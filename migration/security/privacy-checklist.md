# Checklist de privacidade

- [ ] Dump bruto fora do Git e criptografado.
- [ ] Nenhuma tabela real de autenticação exportada.
- [ ] E-mails, sessões, OAuth states e IDs Discord ausentes.
- [ ] UUIDs reais substituídos por pseudônimos com salt externo.
- [ ] Webhooks e chaves Foundry removidos.
- [ ] Avatares e submissões pessoais excluídos.
- [ ] Texto livre revisado para nomes, e-mails, telefones e links pessoais.
- [ ] Contagens, órfãos e checksums verificados.
- [ ] Mapa/salt destruído ou isolado sob controle formal.
- [ ] Dump sanitizado com prazo e controle de acesso definidos.
